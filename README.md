# hep-educatif

A French-language website for learning particle physics. Written courses at three levels (general public, undergraduate, expert) link to an explorer that shows collision events in 3D: reference decay topologies from the Particle Data Group next to real LHC events from CERN Open Data.

## Status

Early development. Nothing is deployed and the repository does not contain application code yet.
